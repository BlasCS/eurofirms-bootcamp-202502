## Commands

### git branch

Muestra todas las ramas

### git status

Muestra la ruta en que nos encontramos

### Git status -u

Muestra la ruta completa del lugar en que nos encontramos

### git log

Muestra todos los commits

### git switch (branch-name)

Te desplaza a la rama seleccionada

### git add file-path

Añade un archico en la ruta indicada

### git commit -m message

vuelve a la rama superior

### git restore file-path

Restaura un archivo eliminado

### git clone repository-url

Clona en nuestro PC un repositorio de Internet (Git Hub)
