# BASH

## Intro

Bash es un intérprete de órdenes que generalmente se ejecuta en una ventana de texto donde el usuario escribe órdenes en modo texto

## Commands

### mkdir

Crea un directorio/carpeta

### ls

Muestra los archivos y carpetas

### pwd

Muestra la ruta del directorio acutal

### cd folder-path

cambiar a otra carperta/directorio

### touch

Crea un archivo

### clear (CTRL + L)

limpia la pantalla
